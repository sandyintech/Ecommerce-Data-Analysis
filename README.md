# E-commerce Data Analysis Using Pandas

## Project Overview
This project analyzes an online retail dataset using Python and Pandas.

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Project Phases
- Phase 1: Dataset Familiarization
- Phase 2: DataFrame Exploration
- Phase 3: Data Selection and Filtering
- Phase 4: Data Transformation and Management
- Phase 5: Data Quality and Missing Value Management

## Dataset
Online retail transaction data containing invoice details, product information, quantities, prices, customer IDs, and countries.
